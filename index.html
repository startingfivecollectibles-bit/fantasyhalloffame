⚔️ Deploy Unit Assessment — Boss Battle

Upload a scored CSV to award individual student XP and deal house damage to the unit boss.
📊
Upload Assessment File to Deploy Challenge Damage
Drag & drop a CSV here, or click to browse — file upload auto-triggers the damage blast
Expected CSV format:
Name column — any of these work: Real Name as "First Last"; an Aeries-style single Name column as "Last, First" (e.g. "Smith, John"); or a Google Classroom export with separate Last Name + First Name columns (Email Address / Grade Level are auto-detected and ignored). Every other column is treated as a standard code.
Scores are 1–4 rubric: 4 = 100 XP (Advanced) · 3 = 75 XP (Proficient) · 2 = 50 XP (Basic) · 1 = 25 XP (Below Basic) · blank = skipped
Examples: Name, Standard 1, Standard 2 (Aeries)  —or—  Real Name, 7.1.1, 7.1.2  —or—  Last Name, First Name, Email Address, Grade Level, 7.1.1, 7.1.2
